 # Solar Panel Energy Optimization Using MPPT and IoT

## 📌 Overview
A smart solar monitoring system built with ESP32 and MPPT algorithm 
to maximize solar panel efficiency with real-time IoT monitoring.

## ✨ Features
- Real-time voltage, current & power monitoring
- MPPT algorithm for maximum energy extraction
- Automatic cooling system based on temperature
- IoT-based live performance tracking

## 🛠️ Tech Stack
- **Microcontroller:** ESP32
- **Algorithm:** MPPT (Maximum Power Point Tracking)
- **IDE:** Arduino IDE
- **Sensors:** Temperature sensor, Voltage/Current sensor

## 📁 Files
- `solar_project.ino` - Main Arduino source code

## 🚀 How to Run
1. Clone this repository
2. Open `solar_project.ino` in Arduino IDE
3. Connect ESP32 as per circuit diagram
4. Flash the code to ESP32
